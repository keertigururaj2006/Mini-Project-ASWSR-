# CrediFit – Admission Stage-Wise Screening Register

## 📌 Project Overview

CrediFit is a web-based Admission Stage-Wise Screening Register designed to simplify and manage the admission screening process.

The system maintains applicant information, verifies submitted documents, checks eligibility, conducts merit screening, and tracks the final admission status.

It provides a structured and transparent way to manage admission records through multiple screening stages.

## 🎯 Objectives

- To digitize the admission screening process.
- To maintain applicant records systematically.
- To verify applicant documents.
- To apply rule-based eligibility checks.
- To track screening results at every stage.
- To reduce manual errors and improve data integrity.

## ✨ Key Features

- Applicant Registration and Profile Management
- Course Management
- Document Verification
- Eligibility Screening
- Merit-Based Screening
- Admission Status Tracking
- Role-Based Access
- Database Record Management
- Screening Results and Reports

## 🔄 Admission Workflow

1. Application Screening
2. Document Verification
3. Eligibility Screening
4. Merit Screening
5. Admission Confirmation

**Screening Status:** PASS / FAIL / PENDING

**Final Admission Status:** ADMITTED / NOT ADMITTED / PENDING

## 👥 User Roles

- **Applicant:** Submits application details and documents.
- **Admission Officer:** Verifies documents and manages screening.
- **Admin:** Manages the overall system and records.
